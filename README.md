# Godot GDVscript - a visual alternative to GDScript

GDVscript is a Godot 4+ addon that enables you to create complex behaviors using a visual-scripting-like graph editor.
With Godot GDVscript, you can create complex stories and dialogues, providing a deep and authentic RPG game experience.

Whether you are an experienced Godot developer or a beginner, GDVscript can help bring your RPG game to life.

## 🚀 Features

* Visual scripting
* Built-in flow control, logic, and utility helper nodes.
* Godot Editor integration
* Support project-specific custom node behaviors
